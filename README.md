# FinalprojectLauraGonz-lez

You can find the deployed site here: [https://lauragonzalezfer10.github.io/PortfoliotemplateLauraGonz-lez/]

## Project description and purpose

The aim of this project is to create a responsive portfolio template that can be used by creatives such as designers, artsists, developers or photographers to showcase their work.

This project focuses on a clean and scalable structure, an interesting UX and a correct adaptation to different devices.

It is designed with my creative point of view but highly customisable for everyone´s liking.

## Tech stack used

The project as been developed using the following technlogies and resources:

- HTML5 in order to create the semantic structure.
- CSS3 for styles, responsive design and visual customisation.
- JavaScript for microinteractions
- Bootstrap: I used a Bootstrap template as a starting point with its framework and utility system and customised it.
- GSAP was used for small text animations to add depth to the project.
- ImageKit.io was used as an API to host and optimise images to decrease loading time.
- Visual Studio code was the tool used to code and define the structure, style and animations of the project.
- GitHub Pages was used to deploy the site launched over HTTPS.

In addition, I used AI as a support for some specific elements and you can find prompts used in the docs with plans and reports.

## Setup instructions for local development

For local development:

1. Clone the repository: git clone https://github.com/lauragonzalezfer10/PortfoliotemplateLauraGonz-lez.git
2. Access the project folder.
3. Open the index.html file in your browser or use VS Code to open it.

## Customization guide

This template is designed to be easily customisable.

- Colours and fonts can be modified in the CSS file. If you edit the theme in CSS you can change the parameters like colours or fonts easily to customise it to your liking.
- All images and texts are placeholders so the designer can add their own work.
- Modular sections and a clear semantic structure enables adding new sections without breaking the design or code.
